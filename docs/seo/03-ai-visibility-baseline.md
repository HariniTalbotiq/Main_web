# AI-visibility baseline — 30 buyer prompts

Run each prompt in ChatGPT, Gemini, Claude and Perplexity. Record: does TalbotIQ appear (yes / no /
mentioned but not linked), which sources are cited instead, and the date. Re-run monthly. Expect zero
appearances until the domain is live and the directory listings (G2, Capterra, GetApp) exist — those
listings, not talbotiq.com, are usually the first pages an assistant cites.
